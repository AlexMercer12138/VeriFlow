## Product scope

This is the first Node CLI deprecation release. The maintained product forms
are the `veriflow` Node CLI and the VS Code extension. The deprecated Python
GUI and CLI remain available as compatibility artifacts until the retirement
gate in Task 11 is completed.

The VS Code extension keeps the compatible identity
`Vikai-mercer.veriflow`; its display name is `Verilog Design Flow`.
